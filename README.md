# JD Resume Matcher

An AI-assisted tool that analyzes job descriptions, matches them with personal experience, and generates resume optimization suggestions.

## Problem

Job seekers often spend too much time manually comparing job requirements with their own experience.

## Planned Features

- Extract key requirements from a job description
- Match requirements with personal experience
- Identify missing keywords and evidence
- Generate tailored resume suggestions
- Provide human-review checkpoints

## Tech Plan

- Python
- Large language model API
- Streamlit or Gradio
- GitHub
